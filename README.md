# كلمات ماسنجر — Kalimat Messenger

تطبيق مراسلة عربي باتجاه RTL، بواجهة داكنة زجاجية وتدرجات زرقاء، مبني على Firebase وWebRTC ويمكن تشغيله كتطبيق ويب أو تغليفه كتطبيق Android عبر Capacitor.

## الميزات الموجودة حالياً

- إنشاء حساب وتسجيل الدخول بالبريد الإلكتروني مع اشتراط تأكيد البريد، واستعادة كلمة المرور.
- البحث عن الأصدقاء بالاسم أو برمز الصديق، ومحادثات فردية ومجموعات.
- رسائل نصية، صور مضغوطة، ملفات صغيرة، ورسائل صوتية.
- الرد على الرسائل، التفاعلات التعبيرية، الحذف للجميع، مؤشرات القراءة، ومؤشر الكتابة.
- حالات مؤقتة، مكالمات صوتية ومرئية عبر WebRTC، وسجل للمكالمات.
- تشفير رسائل المحادثات الفردية باستخدام ECDH P-256 وAES-GCM، مع رمز أمان للمقارنة.
- إعدادات الخصوصية، الوضع الداكن/الفاتح، سمات الألوان، خلفية المحادثة، قفل محلي برقم سري، وأصوات التطبيق.
- تثبيت المحادثات أعلى القائمة وكتم إشعارات محادثات محددة على الجهاز الحالي.
- دعم الواجهة الأساسية دون اتصال عبر Service Worker، وبناء APK تجريبي من GitHub Actions.

## حدود مهمة — لا نريد الادعاء بما لم يُنجز

- **الإشعارات:** إشعارات المتصفح الحالية تعمل عندما يكون التطبيق قادراً على تنفيذ JavaScript. دعم push في Service Worker وحده لا يرسل إشعارات للتطبيق المغلق. يلزم إعداد FCM/Push فعلي واختباره على Android.
- **المجموعات:** رسائل المجموعات غير مشفّرة طرفاً لطرف في النسخة الحالية؛ لا ترسل فيها معلومات حساسة.
- **المفاتيح:** مفتاح التشفير الخاص محفوظ محلياً في المتصفح/الجهاز. مسح بيانات الموقع أو حذف بيانات التطبيق قد يجعل الرسائل القديمة غير قابلة لفك التشفير. لا توجد بعد آلية آمنة لنقل المفاتيح بين الأجهزة.
- **الملفات:** المرفقات تُخزّن ضمن الرسائل، لذا يجب إبقاؤها صغيرة. لا يوجد حالياً تخزين ملفات سحابي مخصص.
- **المكالمات:** جودة الاتصال تعتمد على المتصفح والشبكة وأذونات الميكروفون/الكاميرا؛ قد تحتاج بعض الشبكات إلى خوادم TURN لتحسين نجاح الاتصال.
- **قواعد Firebase:** يجب ضبط قواعد Firestore في مشروع Firebase لتمنع القراءة والكتابة غير المصرح بهما. لا تعتبر إعدادات العميل أو إخفاء عناصر الواجهة بديلاً عن قواعد الخادم. اختبر القواعد قبل فتح التطبيق للمستخدمين.
- **الاعتمادية:** نجاح بناء APK لا يثبت وحده أن التسجيل والرسائل والتشفير والإشعارات والمكالمات تعمل على كل جهاز. يلزم اختبار عملي بحسابين وجهازين.

## بناء APK

1. افتح المستودع ثم تبويب **Actions**.
2. اختر **Build Kalimat Messenger APK**.
3. افتح أحدث تشغيل ناجح، ثم نزّل **Kalimat-Messenger-APK** من قسم Artifacts.
4. فك ضغط الملف المنزّل وثبّت APK على جهاز Android. قد يطلب Android السماح بالتثبيت من هذا المصدر.

هذا البناء مخصص للتجربة؛ قبل التوزيع العام نحتاج إلى إعداد إصدار موقّع، ومراجعة قواعد Firebase، واختبار الوظائف على أجهزة فعلية.

## خطة التطوير التالية

1. مراجعة قواعد Firestore وتطبيقها واختبارها بأمان.
2. تهيئة إشعارات FCM الأصلية مع اختبار وصولها عندما يكون التطبيق مغلقاً.
3. تحسين المجموعات وصلاحيات المشرفين وإدارة الأعضاء.
4. اختبار التشفير واسترجاع المفاتيح والرسائل على جهاز جديد.
5. إضافة تحسينات الاستخدام مثل الأرشفة والبحث داخل سجل الرسائل، ثم اختبارات Android فعلية.
